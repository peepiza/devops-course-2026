# Мои цели на семестр

1. **Освоить Docker** — научиться контейнеризировать приложения, писать Dockerfile и docker-compose.yml.

2. **Разобраться в CI/CD** — настроить пайплайн GitHub Actions для автоматической сборки, тестирования и деплоя.

3. **Изучить Linux (Bash)** — уверенно работать в командной строке, писать bash-скрипты для автоматизации.
