# Git в VS Code vs терминал

## Что удобно в VS Code:
1. Визуализация diff — сразу видно, что изменилось, без `git diff`.
2. Встроенный редактор merge-конфликтов — можно выбрать «Accept Current/Incoming».
3. История коммитов и веток в боковой панели — не нужно помнить команды.
4. GitLens показывает, кто и когда менял каждую строку (аналог `git blame`).

## Что удобнее в терминале:
- Сложные операции (rebase, cherry-pick, squash) — в терминале больше контроля и понятнее, что происходит.
